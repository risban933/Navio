Safari extension

Welcome to Navio

Automatically open supported Google Maps links in Apple Maps on iPhone and iPad.

Set up access

Navio only needs access to the Google domains you enable in Safari. It does not request blanket website access.

  1. 1
    Open Settings Go to the Settings app on your device.
  2. 2
    Open Safari Extensions Navigate to Safari, then Extensions, and select Navio.
  3. 3
    Enable Navio Turn the extension on so Safari can handle supported links.
  4. 4
    Allow Google websites When Safari asks, allow access only on supported Google domains.

Navio is limited to supported Google domains such as google.com and google.co.uk. It does not use blanket site access and does not collect or store personal data.

What Navio does

  • One-tap navigation from Google Search to Apple Maps
  • Works on supported Google country domains
  • Supports addresses, places, and directions
  • Lets you pause redirects at any time
  • No data collection
